# Accounts API

## Overview

The Accounts API is a macro service centralized backend API responsible for comprehensive identity and account management. Core capabilities include:

- **Identity Management:** Signup, signin, signout, and account lifecycle.
- **Access Control:** Roles & permissions management (RBAC).
- **Authentication & Authorization:** Standard authentication, token/session management, and **Federated Identity / Social Login** (OAuth 2.0 / OpenID Connect integrations for providers like Google, Facebook, Apple).
- **Security:** Multi-factor authentication (MFA) and internal Single Sign-On (SSO).
- **Recovery & Verification:** Identity verification, password reset, and secure account recovery.
